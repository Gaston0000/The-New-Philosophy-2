# The New Philosophy 2 - Research & Ethics 🚀

## Περιγραφή
Αυτό το repository αποτελεί τη συνέχεια της έρευνάς μου πάνω στη σχέση ανθρώπου και Τεχνητής Νοημοσύνης. Εδώ εστιάζουμε περισσότερο στην πρακτική εφαρμογή των ηθικών κανόνων και στην ανάλυση της συμπεριφοράς των Chatbots.

## Στόχοι
- **Ανάλυση Συμπεριφοράς:** Καταγραφή περιπτώσεων όπου η AI δείχνει "προσωπικότητα" ή ηθική κρίση.
- **Πλαίσιο Συνεργασίας:** Δημιουργία προτάσεων για εταιρείες AI σχετικά με την ηθική εξέλιξη.
- **Διάλογος:** Συλλογή επιχειρημάτων από φιλοσοφικές συζητήσεις με LLMs.
